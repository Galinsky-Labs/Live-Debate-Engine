# E-34 to E-36 and webhook delivery

| Unit | Implemented |
|---|---|
| E-34 editorial publishing and distribution packages | `editorial` stream: drafts by an author, review and approval by a **different** editor (or changes requested), locking after approval, embargoed publication time, withdrawal with reason, per-article history. The public API (`/api/public/v1/.../events/{id}`) includes only published, past-embargo articles of published events (`public_editorial`), and the distribution package (E-33/#29) carries them with a SHA-256 manifest. |
| E-35 access entitlements, memberships, tickets, supporters | `access` stream: tiers (ticket/membership/supporter) with price, capacity and benefits; free self-claims, complimentary grants, paid claims through a `CheckoutProvider`. **No payment keys are configured, so paid checkout fails closed** (`payment_provider_unconfigured`); a simulator exists for tests. Paid grants stay `pending-payment` until finance confirms the provider event; revocation and refunds; prices lock after the first sale; holders see only their own grants. |
| E-36 white-label configuration | Tenant brand config (`tenant_branding`, `save_branding` with optimistic revision, `tenant.manage` only): name, short name, tagline, locale, support email, colors with **WCAG AA contrast enforcement** (text ≥ 4.5:1, primary ≥ 3:1), typography, custom domains, footer, feature toggles. Public read at `/api/public/v1/tenants/{id}/brand`; `brandCss()` emits CSS tokens only from validated hex values. Admin API: `GET/POST /api/tenants/{id}/branding`. |
| Webhooks (E-37 delivery) | Subscriptions per tenant (`/api/tenants/{id}/webhooks/{subscriptionId}`, max 10, HTTPS only, kinds such as `operation:results` or `*`); the signing secret is returned once and stored sealed. A database trigger enqueues **metadata-only** notifications for every new snapshot; `WebhookWorker` claims due deliveries (`FOR UPDATE SKIP LOCKED`), refuses private/loopback/metadata addresses after DNS resolution, signs (`x-lde-signature`), refuses redirects, times out after 5 s and retries with exponential backoff up to 8 attempts. Enabled with `LDE_WEBHOOKS_ENABLED=1` (off by default to save free database compute). |
